# Tasks and reminders

[Today](https://noesis.seges.ai/en/today/) helps you track a practical next step. You can also use task operations in an AI connection when they are available and you have granted that connection the required access.

## Make a useful task

Choose a clear title and the next action you want to take. Add a start time or deadline only when it is useful and known. You can leave either unspecified. A task records an intention; marking it complete does not independently prove a real-world outcome.

## Use a connected assistant

Tell your assistant which task to create or change. The assistant should use the operations available in your current connection and the applicable permissions. A general Noesis sign-in, reflection consent or profile permission does not grant task access.

You review connection permissions in signed-in Noesis. Reminder enablement has its own settings review. The assistant cannot enable a permission or approve a request for you.

If the connected action is unavailable, your assistant can prepare a task draft for you to add in Today. If a response is unclear, check the existing task or original operation before creating a duplicate.

## Work in your preferred language

You can describe the task in your own language. Keep the intended date, time and timezone explicit when they matter; otherwise leave them open.
