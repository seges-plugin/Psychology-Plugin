# Product and connection names

The plugin and MCP connection are named **Psychology**. Noesis is the website and account service used by the connection.

| Setting | Value |
| --- | --- |
| Plugin name | `Psychology` |
| MCP connection name | `Psychology` |
| MCP endpoint | `https://noesis.seges.ai/mcp` |
| MCP tool namespace | `psychology_` |
| Workflows package identifier | `psychology-workflows` |

Use the exact connection name shown by your host when managing its permissions. Avoid duplicate active entries for the same endpoint. Renaming a local connection does not transfer credentials, change your saved records or add permissions.
