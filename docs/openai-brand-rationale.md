# Psychology visual identity

The four curved forms hold a shared center. They represent selected memories and conversations coming together around a person's own reflection, while leaving open space so context is not mistaken for a fixed or complete profile.

The same geometry appears in the light and dark SVG variants. Deep green and warm gold match the existing square composer icon; the dark variant uses brighter versions of those same colors for contrast. At small sizes, the four broad shapes and central circle remain legible without text, gradients, or fine detail.

Assets:

- `assets/logo-light.svg`
- `assets/logo-dark.svg`
- `assets/icon.png` (square composer and listing icon)

The SVGs are self-contained, use a square `0 0 256 256` viewBox, and contain no remote assets, scripts, or embedded font dependencies.
