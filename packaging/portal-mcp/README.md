# Psychology

This archive is intended for the existing **With MCP** submission flow, not a
Skills-only upload. Verify the saved Portal component inventory and connected
MCP after import. A local archive check does not prove import acceptance.

Connect **Psychology** at `https://noesis.seges.ai/mcp` through the host's
browser OAuth flow. Use the available operations for a requested reflection
guide, psychometric instrument discovery, exact item materials, or selected
Noesis records. Use only capabilities actually exposed by the connected host.

Stored records require current consent and an explicit source choice before
reading. Writes need the applicable authorization and review. An installed
connection does not authorize background account reads, automatic memory capture,
or unsolicited saving. The service cannot retrieve another account's unavailable
conversation archive. Do not use copied credentials or invent a tool alias.

Psychometric results support non-clinical reflection, not diagnosis or treatment.
Only confirmed eligible responses enter scoring. Disclose missing item scales
rather than inventing them. Professional listings are unverified leads; check
credentials, availability and suitability independently. This is not an emergency
or crisis service.

Installation, successful discovery, an authenticated call, and directory approval
establish different things. Host availability and current tool schemas must be
checked in the actual connection. No universal host support is claimed.

Read the [privacy policy](https://noesis.seges.ai/privacy),
[terms](https://noesis.seges.ai/terms) and
[support guidance](https://noesis.seges.ai/support/).
