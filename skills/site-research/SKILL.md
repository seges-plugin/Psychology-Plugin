# Public-site research

## Purpose

Use this guide before describing Noesis, onboarding a host, or answering a product question whose answer may have changed.

## Read-only method

1. Fetch `https://noesis.seges.ai/` and the directly relevant public page.
2. Record the URL, retrieval date, visible claim, and whether the page is public product copy or technical evidence.
3. Treat a status response, page load, or configuration example as partial evidence only.
4. Confirm client support only from an explicit named-client acceptance record.
5. Link back to the public page rather than copying a user's account data into notes.

## Claim discipline

Use these labels:

- **Observed** — visibly present on the current public page.
- **Verified integration** — a named host and version completed the relevant connection checks.
- **Planned** — an intention with no completed acceptance record.
- **Unknown** — do not infer an answer from a similar host or an old document.

## Public contact

For an error report or access question, use the public Noesis site: https://noesis.seges.ai/
