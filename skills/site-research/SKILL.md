# Public-site research

## Audience and privacy

Follow the [account age rules](../00-session-bootstrap/SKILL.md#audience-and-age-appropriate-privacy). Under 13: general or safety help only; no personal collection, account reads or saving. Ages 13-17: account work is limited to server-permitted ordinary tasks/goals, optional dates and user-enabled reminders. Unknown age grants no restricted processing or persistence. Never bypass restrictions through another tool/store/file. Ordinary non-sensitive conversation may continue. Declaring 18+ grants no optional-purpose consent; keep required source/action/connection permissions and instrument rights.

## Resolve the question with current public evidence

Reuse the person's actual goal and the fresh public sources already fetched for this task. Fetch only
a missing time-sensitive fact, then give a practical answer with its evidence boundary. Public-page research does not read
private account context, grant retention or execute outreach. If an action is requested, carry the
established task forward to the applicable supported workflow without promising an unobserved result.

## Purpose

Use this guide before describing Psychology, onboarding a host, or answering a product question whose answer may have changed.

## Read-only method

1. Fetch `https://noesis.seges.ai/` and the directly relevant public page.
2. Record the URL, retrieval date, visible claim, and whether the page is public product copy or technical evidence.
3. Treat a status response, page load, or configuration example as partial evidence only.
4. Use current host documentation and actually visible capabilities to describe client support.
5. Link back to the public page rather than copying a user's account data into notes.

## Claim discipline

Use these labels:

- **Observed**: visibly present on the current public page.
- **Connected in this session**: the required tool is currently callable in the host.
- **Unavailable**: a required capability is absent or cannot complete the requested action.
- **Unknown**: do not infer an answer from a similar host or an old document.
