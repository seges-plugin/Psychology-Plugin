# Changelog

## 1.4.4 candidate (unreleased)

- Add a connected Life journey: approve the AI connection in Account, then manage
  one task at a time. Titles work without a start or deadline; keep date-only
  values separate from exact times. Today remains the fallback.
- Read and review reminder preferences separately. Updating settings is not a
  delivery receipt and never authorizes an email by itself.
- Recover the status of an exact profile review. Reuse the same supported request
  ID after a lost preparation response; never create a second save from a status.
- Include the guide and contract referenced by the full workflows package; retain
  the separate eight-file MCP-only package, 16 skills and unchanged OAuth setup.

The backend image has passed source, runtime and supply-chain artifact checks.
New backend deployment, schema and feature acceptance, authenticated discovery,
package publication and host acceptance are still separate. This candidate is
not an installed-host update. The current published package remains 1.4.3.
Relationship, finance, learning and other domain-MCP candidates are not included.

Existing non-clinical, explicit source selection, owner review, psychometric and
account export/deletion rules remain. No new assessment scoring or save behavior
is introduced.
